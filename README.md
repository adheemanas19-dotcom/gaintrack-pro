# GainTrack Pro

A general-purpose fitness tracker designed for Android and Google Play release.

## Included
- First-run onboarding
- User profile and goals
- Push, Pull, Legs, Upper, Lower and Full Body plans
- Individual exercise set tracking
- Weight logging and history
- Weight progress chart
- Workout history
- Personal best tracking
- Workout streak calculation
- Custom workout creator
- Dark/light mode
- KG/LB display preference
- Local on-device data persistence

## Build
This project is a Flutter source project. On a machine or cloud builder with Flutter:

1. `flutter create .`
2. `flutter pub get`
3. `flutter run`
4. For Play Store: `flutter build appbundle`

The final Play Store upload file is:
`build/app/outputs/bundle/release/app.aab`

## Important
Before publishing, test on real devices, create a privacy policy matching the final data practices, complete Play Console's Data Safety form accurately, and follow Google's testing requirements.
